# Loan Default Risk Dashboard

A simple web-based dashboard built with Python and Streamlit to visualize loan default risk data.

## Features

*   Displays borrower data in a sortable table.
*   Filters data by borrower name.
*   Color-codes the predicted default probability for easy risk assessment.

## How to Run

1.  **Install dependencies:**

    ```bash
    pip install streamlit pandas
    ```

2.  **Run the application:**

    ```bash
    streamlit run loan_default_risk_dashboard/app.py
    ```
